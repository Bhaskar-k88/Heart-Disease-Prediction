# Heart Disease Prediction using Machine Learning

This project predicts whether a person has heart disease or not using Logistic Regression.

---

# 📌 Project Overview

The model is trained using medical data such as:

- Age
- Sex
- Chest Pain Type
- Blood Pressure
- Cholesterol
- Maximum Heart Rate
- Exercise Induced Angina
- ST Depression

The project performs:
- Data preprocessing
- Data analysis
- Feature scaling
- Model training
- Prediction
- Accuracy evaluation

---

# 🛠 Technologies Used

- Python
- NumPy
- Pandas
- Scikit-Learn
